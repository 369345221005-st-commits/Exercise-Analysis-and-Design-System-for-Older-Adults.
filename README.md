##ปัญหาและกลุ่มเป้าหมาย 
ปัญหาที่พบ (Problem) : ผู้สูงอายุที่ต้องการออกกำลังกายมักประสบปัญหาการขาดความรู้ในการจัดตารางฝึกที่เหมาะสมกับสภาพร่างกายตนเอง ขาดการประเมินความพร้อมด้านสุขภาพก่อนเริ่มออกกำลังกาย หรือไม่ทราบระยะเวลาและขั้นตอนท่าทางที่ถูกต้อง ส่งผลให้เกิดอาการบาดเจ็บหรือไม่บรรลุเป้าหมายด้านสุขภาพอย่างยั่งยืน
กลุ่มเป้าหมาย (Target Audience) : ผู้สูงอายุ ที่ต้องการเริ่มต้นออกกำลังกายอย่างถูกวิธี และผู้ดูแลสุขภาพ
## ฟีเจอร์หลักและขั้นตอนทดสอบ (ตารางในข้อ 3) 
1.ระบบวิเคราะห์และประเมินสุขภาพ : 1.เข้าหน้าประเมินสุขภาพ 2.เลือกช่วงอายุและตอบคำถามสุขภาพ
2.ระบบแนะนำและเลือกรายการฝึกออกกำลังกาย :1. เข้าหน้าแรก หรือ หน้ารายการฝึก (/products) 2. เลือกรายการฝึกออกกำลังกาย
3.ระบบบันทึกและคำนวณเวลารวมตารางฝึก : 1. กดปุ่ม "เพิ่ม" รายการฝึกเข้าตารางสะสม 2. เข้าหน้าตารางสะสม (/cart) เพื่อตรวจสอบแผนการฝึก
4. ระบบจัดการข้อมูลหลังบ้าน (Supabase Admin) : 1. เข้าหน้าแดชบอร์ดหลังบ้านผู้ดูแล (/admin หรือ Supabase) 2. แก้ไขหรือเพิ่มรายการท่าฝึกออกกำลังกายในระบบฐานข้อมูล
5. หน้าสรุปผลกระทบ (Impact Page) : 1. เข้าหน้า /impact 2. ตรวจสอบสถิติภาพรวมและการเก็บข้อมูลหลักฐานการลงพื้นที่
## เทคโนโลยีที่ใช้ (Vue, Vite, Supabase ...)
Vue.js 3 (Composition APL / Vue Router)
Supabase (Database & Real-time Subscriptions & RLS)
Vite (Frontend Build Tool)
## วิธีติดตั้งและรัน
1. ติดตั้ง Node.js รุ่น LTS
2. คัดลอก .env.example เป็น .env.local แล้วใส่ค่า VITE_SUPABASE_URL และ VITE_SUPABASE_KEY
3. npm install
4. นำเข้าฐานข้อมูลจาก database/
5. npm run dev แล้วเปิด http://localhost:5173
